# java-racingcar-precourse

## 구현할 기능 목록

1. 사용자 입력 처리
   - [ ] 자동차의 이름 목록을 입력 받는다.
     - [ ] 자동차 이름은 ","로 구분한다
     - [ ] 자동차 이름이 5자를 넘어서면 예외를 발생시킨다.
     - [ ] 같은 이름이 존재하면 구분이 안되므로 같은 이름이 입력되면 예외를 발생시킨다.
   - [ ] 자동차들의 자동차의 이동 횟수를 입력 받는다.
     - [ ] 이동 횟수는 자연수로 한정한다. 그 외의 값이 들어오면 예외를 발생시킨다.
2. 자동차 경주
    - [ ] 이동횟수만큼 자동차들을 차례로 전진시킨다.
      - [ ] 현 회차에서 모든 자동차들을 한번씩 전전시킨 후에 다음 회차로 넘어간다.
    - [ ] 자동차는 난수 값에 따라서 전진한다
      - [ ] 각 자동차는 0 ~ 9 사이의 난수를 뽑았을 때 그 값이 4 이상이면 전진시킨다.
3. 경주 과정 및 결과 출력
   - [ ] 경주 중에 자동차들을 한번씩 전진시킨 결과를 차례대로 출력한다.
     - [ ] 각 자동차는 "이름 : 이동거리" 형태로 출력한다.
     - [ ] 이동거리는 "-" 문자를 자동차가 이동한 거리만큼 출력한다.
   - [ ] 경주가 끝나면 최종 우승자를 출력한다.
     - [ ] 최종 우승자는 가장 먼 거리로 이동한 자동차다.
     - [ ] 최종 우승자가 여럿이면 ", "로 구분하여서 출력한다.
